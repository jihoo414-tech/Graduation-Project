# 현재 범위 기준 의사 페르소나 정의

## 문서 목적
이 문서는 현재 프로토타입 범위에서 실제로 서비스 가치가 분명한 **의사 사용자 페르소나**만 정의한다.

현재 서비스 범위는 다음과 같이 본다.
- 비식별 환자 1건 업로드
- 재발 위험 결과 확인
- 전문의용 요약 확인
- 환자 설명용 문장 초안 준비
- 리포트/메모 형태로 정리

따라서 아래 페르소나는 **대형 병원 전사 시스템**, **다학제 회의 전용 도구**, **연구 분석 플랫폼**까지 확장된 상황은 포함하지 않는다.

---

## Persona 1. 외래에서 환자 설명까지 책임지는 종양내과 전문의

### 한 줄 정의
바쁜 외래 진료 중 유전체/임상 결과를 빠르게 해석하고, 환자에게 설명할 문장을 짧은 시간 안에 준비해야 하는 핵심 사용자.

### 기본 프로필
- 직무: 종양내과 전문의
- 근무 맥락: 상급종합병원 또는 암센터 외래
- 디지털 숙련도: 중간 이상
- 데이터 해석 성향: 결과 자체보다 **진료실에서 바로 사용할 수 있는 요약**을 선호

### 현재 업무 맥락
- 진료 전에 환자 검사 결과와 임상 정보를 빠르게 훑어봐야 한다.
- 유전체 결과를 진료실 언어로 바꿔 설명해야 한다.
- 환자 질문에 대비해 위험도 결과를 지나치게 단정하지 않으면서도 이해 가능하게 전달해야 한다.
- 진료 시간이 짧아서 결과 해석과 환자 설명을 따로 준비하기 어렵다.

### 주요 목표
1. 결과를 1~2분 안에 파악한다.
2. 위험도와 주요 영향 요인을 빠르게 확인한다.
3. 환자에게 바로 전달 가능한 설명 초안을 얻는다.
4. 진료 후 메모나 리포트 형태로 남길 수 있다.

### 주요 어려움
- 유전체/임상 정보를 함께 해석하는 데 시간이 든다.
- 결과를 환자 눈높이로 다시 바꾸는 작업이 반복적이다.
- 의료적으로 안전한 표현과 쉬운 표현 사이 균형을 잡기 어렵다.
- 외래 흐름이 빠르기 때문에 설명 문장을 매번 새로 만드는 부담이 크다.

### 기대하는 서비스 가치
- 결과 핵심을 짧게 요약해준다.
- 위험도 근거를 한 화면에서 바로 확인할 수 있다.
- 환자 설명용 문장을 바로 복사하거나 메모로 저장할 수 있다.
- 과장 없이, 진료실에서 쓰기 무난한 표현으로 정리해준다.

### 서비스 사용 장면
- 외래 시작 전 케이스를 빠르게 검토할 때
- 환자 입실 직전 설명 문장을 점검할 때
- 진료 후 상담 내용을 간단히 정리할 때

### 자주 보는 정보
- 위험도 레벨
- 위험 점수
- 주요 영향 요인
- 환자 설명용 요약
- 리포트/저장 기능

### 성공 판단 기준
- 결과를 이해하는 데 추가 해석 시간이 크게 들지 않는다.
- 환자에게 설명할 문장을 거의 수정 없이 사용할 수 있다.
- 설명 후 메모 정리가 빨라진다.

### 이 페르소나를 현재 범위의 핵심 사용자로 보는 이유
현재 프로토타입의 전체 흐름은 업로드 → 결과 확인 → 환자 설명 → 리포트로 이어진다. 이 흐름은 진료실에서 설명 책임을 가진 종양내과 전문의의 실제 사용 맥락과 가장 잘 맞는다.

## Persona 2. 설명 초안을 먼저 준비하는 종양내과 펠로우/전공의

### 한 줄 정의
상급자 진료 전에 환자 데이터를 정리하고, 결과를 먼저 확인해 상담 초안을 준비하는 실무형 사용자.

### 기본 프로필
- 직무: 종양내과 펠로우 또는 전공의
- 근무 맥락: 외래/병동/진료 준비 단계
- 디지털 숙련도: 높음
- 데이터 해석 성향: 세부 정보도 확인하지만, 최종적으로는 **상급자에게 전달 가능한 정리본**을 원함

### 현재 업무 맥락
- 검사 결과를 미리 정리해 두고 교수 또는 전문의 진료를 준비한다.
- 입력 데이터가 빠졌는지, 어떤 결과가 핵심인지 먼저 파악해야 한다.
- 환자에게 직접 길게 설명하기보다, 설명 초안과 메모를 준비하는 비중이 높다.
- 자료 정리 시간이 길어질수록 다른 진료 준비 업무가 밀린다.

### 주요 목표
1. 입력 데이터가 정상적으로 들어왔는지 확인한다.
2. 결과의 핵심 요약과 위험도 포인트를 먼저 정리한다.
3. 환자 설명용 초안을 만들어 상급자가 검토하기 쉽게 한다.
4. 케이스 메모나 리포트 형태로 정리해 전달한다.

### 주요 어려움
- 파일 형식과 입력 항목을 맞추는 데 시간이 든다.
- 무엇이 설명에 꼭 필요한 포인트인지 빠르게 잡기 어렵다.
- 상급자 스타일에 맞게 설명 수준을 다시 정리해야 한다.
- 설명 문안을 처음부터 만들면 시간이 많이 든다.

### 기대하는 서비스 가치
- 업로드와 입력 검토 흐름이 단순하다.
- 결과 핵심과 설명 초안을 빠르게 확보할 수 있다.
- 누락 가능성이 있는 정보나 주의 포인트를 눈에 띄게 보여준다.
- 메모/리포트로 남겨 상급자에게 바로 공유할 수 있다.

### 서비스 사용 장면
- 외래 전 케이스 사전 정리
- 교수 회진/상담 전 요약 준비
- 진료 후 기록 정리 보조

### 자주 보는 정보
- 입력 검토 상태
- 결과 요약 카드
- 근거/영향 요인
- 환자 설명용 초안
- 저장/내보내기 기능

### 성공 판단 기준
- 케이스 정리 시간이 줄어든다.
- 설명 초안을 만드는 시간이 짧아진다.
- 상급자에게 전달할 정리본 품질이 일정해진다.

### 이 페르소나를 현재 범위에 포함하는 이유
현재 프로토타입은 협업 기능이나 병원 시스템 연동은 없지만, 단일 케이스 업로드와 요약 생성까지는 충분히 지원한다. 그래서 실제 진료 준비를 맡는 펠로우/전공의도 현재 범위에서 서비스 가치가 분명하다.
